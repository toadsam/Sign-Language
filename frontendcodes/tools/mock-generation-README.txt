생성 API 연결 — 로컬 검증 안내
작성: 2026-10-18

목적
승혁의 프런트에서 문장 입력 → HTTP POST → 응답 검사 → 재생을 독립적으로 검증합니다.
목업은 입력 문장과 관계없이 같은 120프레임 합성 동작을 반환합니다.
수어 생성·단어 인식·모델 정확도를 검증한 결과가 아닙니다.

실행
VSCode 터미널 1에서:
cd /Users/yuseunghyeok/Downloads/Sign-Language-main/frontendcodes
python3 tools/mock-generation-server.py

터미널 2에서:
cd /Users/yuseunghyeok/Downloads/Sign-Language-main/frontendcodes
./node_modules/.bin/expo start --web --localhost --port 8083

브라우저 http://localhost:8083/sign-generate 를 열고
응답 방식 → 로컬 목업 API → 정상 합성 응답 → API 요청하기를 누릅니다.
각 서버는 해당 터미널에서 Ctrl+C로 종료합니다.
목업은 127.0.0.1:8085에만 바인딩합니다. PC웹에서 검증합니다.
화면 내부 샘플은 서버 없이도 사용할 수 있습니다.

오류 시험
미지원 단어, HTTP 503, 잘못된 좌표, JSON 아닌 응답, 느린 응답(3초),
영상 한 개 응답을 선택할 수 있습니다.
느린 응답 + 대기 제한 1초: 시간 초과 안내가 표시되고 다시 요청할 수 있습니다.
요청 취소: 응답을 기다리던 요청을 중단하고 뒤늦은 결과는 표시하지 않습니다.
목업 오류를 성공 샘플로 자동 대체하지 않습니다.

실제 서버를 나중에 연결할 때
'지정한 API'를 고르고 전체 HTTP(S) 주소를 입력합니다.
요청: POST /api/sign/generate, Content-Type: application/json
본문 예: {"text":"안녕하세요"}
이 요청은 Spring 앞단을 위한 임시 어댑터 규격입니다. 팀 통합 때 확정해야 합니다.
추론 서버의 /generate(gloss, nonmanual) 요청과는 별개입니다.
쿠키 및 인증 토큰 전달은 아직 연결하지 않았습니다. 인증·CORS는 통합 때 확인합니다.
목업 CORS는 localhost/127.0.0.1 HTTP 개발 출처만 허용합니다.
화면 입력은 200자 이하, 기본 대기 제한은 15초이며 변경할 수 있습니다.
응답은 기존 decodePlayback으로 검사합니다.
단일 videoUrl의 상대 경로는 요청 API 주소 기준으로 해석합니다.
최종 계약의 TranslatePlaybackItem 형식을 따르는 items 목록 어댑터를 추가했습니다.
생성 응답은 {source:"video",items:[{word,id,file,url,hasVideo}],unknown:[]} 형식을 받습니다.
기존 단일 videoUrl도 한 항목 목록으로 변환합니다. 기존 /translate 호출은 변경하지 않았습니다.
HTTPS로 배포한 화면에서 HTTP 서버로 요청하면 브라우저가 차단할 수 있습니다.

자동 검증 (목업 서버 실행 상태)
node tools/check-generation-api.cjs

검증 내용: POST 본문, 좌표 응답, 미지원 목록, HTTP 오류, 잘못된 JSON/스키마,
영상 URL, 시간 초과, 취소/이미 취소된 요청, 입력/주소 검사, 로컬 CORS, 재시도.
이전 단계에서 브라우저의 단일 목업 응답 재생과 시간 초과 안내를 확인했습니다.
목록 추가 후에는 자동 검증을 통과했으며, 브라우저 연속 재생은 도구 연결 오류로 미확인입니다.
실제 모델·팀 서버·모바일 기기를 사용한 검증은 하지 않았습니다.

영상 목록 시험 (2026-10-18 추가)
/sign-generate → 화면 내부 샘플 → 영상 목록 샘플 → 샘플 동작 보기.
또는 로컬 목업 API → 영상 목록 응답 → API 요청하기.
목록 재생을 누르면 첫 영상 종료 후 '영상 없는 샘플'을 건너뛰고 세 번째 항목을 재생합니다.
목록 반복이 꺼져 있으면 마지막 영상 끝에서 멈춥니다.
이전·다음 또는 단어 버튼으로 직접 선택할 수 있으며, 직접 선택한 뒤에는 재생을 눌러 시작합니다.
영상 없는 단어와 미지원 단어 목록은 구분해서 표시합니다.
빈 영상 목록, 중간 영상 파일 오류 응답도 로컬 목업에서 선택할 수 있습니다.
오류 시 자동으로 성공 처리하지 않으며 '영상 다시 불러오기' 또는 다음 항목 선택으로 복구합니다.
이 화면의 목록 전환 구현과 실제 팀 서버·기존 번역 화면 통합은 별도입니다.
