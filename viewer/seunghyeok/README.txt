승혁의 첫 동작 재생

1. index.html을 브라우저로 열면 됩니다. 별도 설치나 로그인은 필요 없습니다.
2. 재생을 눌러 화면 점검용 동작을 확인하세요.
3. 프레임 슬라이더를 움직이면 정지한 자세를 볼 수 있습니다.
4. 속도를 0.5로 선택하면 느리게 볼 수 있습니다.
5. 동작 JSON 열기로 팀 계약 ⑤의 샘플 응답을 불러옵니다.

기본 동작은 합성한 화면 점검용 데이터입니다. 실제 수어·학습 데이터·모델 성능이 아닙니다.
이 파일은 서버에 좌표나 영상을 보내지 않습니다.
현재 단계는 독립 HTML 재생 확인이며, 다음 단계에 React SignPlayer로 옮깁니다.
