## 1. 준비

### A. VM 없이 (언제든)

터미널 두 개.

```bash
cd ~/Downloads/Sign-Language-main/frontendcodes && python3 tools/mock-generation-server.py
```

```bash
cd ~/Downloads/Sign-Language-main/frontendcodes && npx expo start --web --port 8081
```

- 가짜 서버(8085)는 입력과 상관없이 **같은 합성 동작**을 돌려준다. 문장 모드 흉내는 `?scenario=sentence`(띄어 쓴 낱말마다 자막 구간).
- 통역 화면을 가짜 서버로 열기: `http://localhost:8081/translator?gen=http://localhost:8085/api/sign/generate?scenario=sentence`

### B. VM 있을 때 (지헌에게 시간 확인 후)

1. 단톡에 "VM 쓴다, 약 30분" 알린다. VM 전원은 지헌이 관리한다.
2. **먼저 상태를 본다.** 다른 사람이 서버를 이미 켜 두었을 수 있다 (11/17에는 재훈 계정의 추론 서버 · Spring이 켜져 있었고, 배포 앱이 이를 부를 수 있다).
   ```bash
   gcloud compute ssh <내 계정>@sign-ml --project=project-bd08e20d-00af-4b04-81b --zone=asia-northeast3-b --command 'nvidia-smi; bash /data/work/jiheon/serve_vm_sentence/status.sh'
   ```
   - "추론 서버 8000: 정상 / Spring 8080: 정상"이면 **켜지도 끄지도 않고** 아래 3의 포트 연결만 한다.
   - 아무것도 안 켜져 있을 때만 4에서 직접 켜고, 끝날 때 직접 끈다.
3. 포트 연결 (8080 앱 API, 8000 검증 화면):
   ```bash
   gcloud compute ssh <내 계정>@sign-ml --project=project-bd08e20d-00af-4b04-81b --zone=asia-northeast3-b -- -L 8080:127.0.0.1:8080 -L 8000:127.0.0.1:8000
   ```
4. (꺼져 있을 때만) VM 안에서 문장 서버 켜기 (1~2분): `bash /data/work/jiheon/serve_vm_sentence/start_sentence.sh`
   단어 모델(`serve_vm/start.sh`)과 같은 포트를 쓰므로 둘 중 하나만 켠다.
5. 통역 화면을 실제 서버로 열기: `http://localhost:8081/translator?gen=http://localhost:8080/api/sign/generate`
   통역 화면은 로그인이 필요하다. 로그인 화면에서 "로그인 없이 둘러보기"로 들어간 뒤 위 주소를 다시 연다.
   첫 요청은 1~8초 걸릴 수 있다. 시연 전에 한 번 미리 보내 둔다.

### 0:00 역할 소개 — `/sign-lab`
> "저는 AI가 만든 수어 동작 좌표를 사람이 보고 쓸 수 있는 화면으로 만드는 일을 맡았습니다. 모델이 보내는 것은 영상이 아니라 몸과 손 125개 점의 위치이고, 이걸 재생하고 비교하고 따라 해 볼 수 있게 합니다."

작업실 카드("문장 입력과 동작 생성", "네 동작 함께 비교", "코드북 살펴보기", "따라 하고 점수 받기")를 한 번 훑는다.

### 0:30 문장 → 3D 친구 — `/translator`
입력: **저는 학교에 갑니다.**
> "문장을 넣으면 서버가 수어 단어 순서로 바꾸고, 모델이 토큰을 만들고, 그걸 3D 좌표로 되돌려 친구가 수어를 합니다. 아래 낱말 줄은 지금 재생 중인 단어입니다."

- 낱말 줄이 재생에 맞춰 칠해지는 것을 보여 준다 (응답의 segments).
- 시간이 되면 **커피숍에 가고 싶어요.** → "카페 · 가다"로 바뀌는 대체어도 보여 준다 (B일 때만 의미 있음).
- A(가짜 서버)일 때: "지금은 서버 없이 같은 합성 동작을 보여 주는 점검 모드입니다"라고 먼저 말한다.

### 1:40 못 그린 단어 — `/translator`
입력: **지하철을 타고 집에 가요.** (지헌 확인: "집"만 unknown)
> "모델이 배우지 않은 단어는 지어내지 않고, 그릴 수 있는 것만 만든 뒤 못 그린 낱말을 따로 알려 줍니다."

### 2:20 생성 작업실 — `/sign-generate`
- 화면 내부 샘플 → 정상 샘플 → 재생. 자막이 "샘플 구간 1 → 2"로 바뀌는 것.
- 실패 안내 샘플 → 입력 문장이 남아 있는 것.
> "실패해도 입력은 지우지 않고, 서버가 다시 시도해도 된다고 알려 줄 때만 다시 시도 버튼을 보여 줍니다. 실패를 영상으로 몰래 바꾸지 않습니다."

### 3:00 네 동작 비교 — `/sign-compare`
- 합성 샘플 네 칸을 함께 재생 → 일시정지 → 공통 프레임 이동 → 한 칸을 끌어 시점 돌리기.
> "원본, 이어 붙이기(B1), 좌표 회귀(B2), 우리 방법을 같은 시간과 시점으로 봅니다. 사람 평가 영상도 이 화면에서 칸마다 녹화해 무작위 번호로 묶습니다."

지금은 합성 샘플이다. 실제 조건별 동작은 `viewer/seunghyeok/evaluation/export_motion_json.py`로 VM에서 바꿔 넣는다 (아직 실제로 해 보지 않음).

### 3:40 따라 하기 — 통역 화면의 "따라 하기"
- 카메라 켜기 → "따라 하기 시작" → 3 · 2 · 1 → 점수와 고칠 곳.
- 가슴과 손이 화면에 들어오게 한 걸음 물러선다 ("조금 더 뒤로!" 안내가 뜨면).
> "친구 동작 옆에서 따라 하면 손의 자리와 손가락 모양을 시간을 맞춰 견주어 점수와 고칠 곳을 알려 줍니다. 영상은 저장하거나 보내지 않습니다. 점수 기준선은 아직 실제 시도로 맞추는 중입니다."

카메라 권한 창이 뜨면 시연 전에 미리 허용해 둔다.

### 4:30 된 것과 남은 것 — `/sign-lab`
> "재생 · 비교 · 자모표 · 문장 입력과 오류 처리 · 따라 하기 화면을 만들었고, 단어 모델은 실제 서버로 재생까지 확인했습니다. 남은 것은 문장 모델 실제 재생 확인, 사람 평가 영상, 따라 하기 기준선 맞추기입니다."

## 3. 문제가 생기면

| 상황 | 할 일 |
|---|---|
| 통역 화면에서 3D 친구 대신 영상이 나온다 | AI 서버(VM)를 못 부른 것이다. 그대로 말하고, 주소의 `?gen=`과 포트 연결을 확인한다 |
| 첫 요청이 오래 걸린다 | 첫 요청은 1~8초. 미리 한 번 보내 둔다 |
| 503 / 시간 초과 | 다시 시도 버튼을 누른다. 계속되면 지헌에게 서버 상태를 묻는다 |
| 카메라가 안 켜진다 | `localhost`에서 열었는지, 브라우저 카메라 권한을 확인한다 |
| 손이 안 잡힌다 | 한 걸음 물러서 가슴 아래까지 보이게 한다 |
