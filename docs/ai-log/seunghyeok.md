# 승혁 AI 작업 기록

## 2026-10-18 — 로컬 재생기의 현재 토큰 표시

- 목표: 서버 없이 진행 가능한 뷰어 호환성 점검과 현재 토큰 표시 보완.
- AI에게 맡긴 것: 기존 코드와 확보한 팀 README 대조, 토큰 표시 구현, 합성 좌표 기반 자동 검사.
- 바꾼 것: `motion.ts`에 4프레임 단위 토큰 조회를 추가하고 `SignPlayer.web.tsx`에 현재 토큰 번호를 표시했다. 토큰이 없는 구간은 정보 없음으로 표시한다. `tools/check-motion-contract.cjs`를 추가했다.
- 판단 근거 및 사용자 확인: 사용자는 로컬 작업 진행과 yuseunghyuk 브랜치 사용을 지시했다. 4프레임 단위는 팀 README에 명시된 동작이며, 별도의 계약 형식 변경은 하지 않았다. 사용자의 최종 화면 검수는 아직 받지 않았다.
- 검증: 새 검사, 기존 `check-sign-data-validator.cjs`, `npx tsc --noEmit` 모두 통과. 합성 float32 little-endian 좌표의 관절·프레임 순서, 토큰 0과 구간 경계, 없는 토큰, 잘린 좌표 및 NaN 거부를 검사했다. 네트워크 및 실제 AI Hub 데이터를 사용하지 않았다.
- 남은 것: 현재 화면의 브라우저 확인, 최신 `docs/contracts.md` 원문 확보 후 전체 계약 대조, 실제 API 응답 검증. 이번 기록은 이 작업에 한정되며 이전 작업 전체의 기록을 대체하지 않는다.

## 2026-10-26 — 연속 재생 중 토큰 표시 확인과 기능 커밋 준비

- 목표: 이전에 완료하지 못한 연속 재생·일시정지·처음으로 복귀의 토큰 표시 확인.
- AI에게 맡긴 것: 로컬 Expo 실행, 합성 자료로 Safari 조작 및 상태 관측, 기존 기능 자동 검사와 관련 파일 Git 정리.
- 바꾼 것: 제품 코드 추가 변경 없이 이번 검증 결과를 기록했다. 기존 현재 토큰 표시와 전용 검사 파일을 하나의 기능 단위로 기록한다.
- 판단 근거 및 사용자 확인: 사용자가 다음 단계를 실행하도록 요청했고 Safari를 앞으로 띄웠다고 확인했다. 백그라운드 관측에서 프레임이 멈춘 것만으로 재생기 결함이라고 판단하지 않았다.
- 검증: 합성 120프레임·30fps·토큰 0~29 자료로 Safari에서 115프레임/#28, 18프레임/#4를 관측했다. 일시정지는 26프레임/#6에 유지됐으며 처음으로 버튼으로 0프레임/#0 복귀를 확인했다. `check-motion-contract.cjs`, `check-sign-data-validator.cjs`, `npx tsc --noEmit` 통과.
- 남은 것: 실제 모델 응답 및 아이폰의 새 토큰 표시, 최신 계약 전체 대조. 이번 관측은 표시 30fps·수어 정확도 검증이 아니다. 클라우드 접속·실제 데이터 사용·main 변경은 하지 않았다.

## 2026-10-26 — E5 자모표와 원본·복원 가져오기 정리

- 목표: 앞서 구현한 실제 팀 자료 가져오기 기능을 검토하고 관련 소스를 독립된 커밋으로 정리.
- AI에게 맡긴 것: 기존 변경 검토, 자모표 파서 검사, 비교 파일 파서와 제목 보존 검사 추가, TypeScript 검사와 선택 커밋.
- 바꾼 것: 55관절 XY 전용 `TokenAtlas.web.tsx`·`token-atlas.ts`와 격자 연결, 비교 파일 labels의 입력 검증·화면 보존 변경을 기록한다. 기존 자모표 검사에 더해 `tools/check-ai-viewer.cjs`로 제목 기본값·오류와 좌표 디코딩을 검증한다.
- 판단 근거 및 사용자 확인: 사용자는 다음 단계 진행을 지시했다. 자모표의 없는 깊이·얼굴 좌표를 만들지 않고 2D로 처리하며, 원본·복원 자료에 있는 얼굴 평균 고정 설명을 유지한다. 공통 계약이나 다른 담당 모델은 수정하지 않는다.
- 검증: 로컬 자모표 파일의 512개·4프레임·55관절·2D 검사 통과. 비교 파일의 8클립 모두 원본/복원 디코딩 및 프레임 수·FPS 일치 검사 통과. 제목 보존과 기본값, 잘못된 제목·관절 순서·FPS·클립 번호·잘린 좌표·비유한 좌표 거부 검사, `npx tsc --noEmit` 통과. HTML 스크립트는 실행하지 않으며 검사 출력은 요약만 남긴다.
- 남은 것: 8클립 전체 화면 검수, 새 기능의 아이폰 파일 처리, 성능·최신 계약·실제 API 확인. 실제 파일은 Downloads에 유지하고 Git에 포함하지 않는다. 이번에는 브라우저 재검증·모델 정확도 평가·서버 접속·원격 push를 하지 않는다.
