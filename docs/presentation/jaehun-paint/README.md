# 손짓의 알파벳 · 자모표 — 3D 발표, 색칠 마을 버전 (재훈 파트)

`../jaehun-show`(귀여운 보라 버전)와 장면·데이터·인터랙션은 같고, 겉모습을 앱 시안 「색칠 마을」(proto-paint)에 맞춘 버전.
수채 종이 바탕 + 먹선 + 물감(노랑·산호·잎·하늘·민트), 글꼴 고운바탕(이야기·숫자)·고운돋움(본문), 손그림 테두리 쪽지와 테이프.

- **색칠 = 배운 것**: 장면은 연필 스케치로 놓였다가 물감이 번지며 칠해진다. 스티커판은 쓰인 칸에만 색이 칠해지고(장면 2),
  귀 오류가 드러나면 캐릭터의 색이 빠졌다가 고치면 다시 칠해진다(장면 3). 자모표 복원은 실제 사람 그림 위에 따라 그린 연필 선(장면 4),
  막대는 연필 윤곽이 솟고 붓이 아래에서 위로 칠한다.
- **3D 수채**: `MeshToonMaterial` 셰이더를 고쳐 종이가 비치는 투명 수채, 그늘 덧칠, 가장자리 물자국, 종이 이에 고인 물감 알갱이,
  얼룩지게 번지는 색칠(paint 0→1)을 만든다. 먹선은 뒷면을 부풀린 껍질(inverted hull)이고 화면에서 2px 안팎, 0.16초마다 떨린다(시안의 rough 필터와 같은 박자).
- **전환**: 시안의 brush. 큰 붓 세 번이 화면을 덮고 지나가며 다음 장면을 드러낸다. 물감 방울·번짐(bloom)이 반짝이를 대신한다.
- 캐릭터는 실제 125점 중 상체 13 + 양손 42를 그대로 따라 움직이고, 머리는 두 눈·목으로 방향만 잡는다(표정은 데이터에서 만들지 않음).

만져 볼 수 있는 것: 스티커 칸을 누르면 그 토큰 카드(0.13초 동작, 단어·문장 클립 수, 자주 나오는 단어), 캐릭터를 누르면 콩 뛰기,
'단어로 찾기'(장면 1·2·6)에 "학교"를 치면 그 단어에 자주 나오는 토큰이 반짝, 장면 3의 "귀 제자리로 돌려놓기" 버튼.

## 실행

```bash
python docs/presentation/jaehun-paint/tools/serve.py 8767
```

`http://127.0.0.1:8767` 을 연다. 512칸만 따로 보려면 `http://127.0.0.1:8767/grid.html`(이 페이지는 아직 보라 버전 화면) (모든 칸이 계속 움직이고, 칸을 누르면 크게 보기 · ←/→ 로 이웃 토큰 · 단어로 찾기 · Space 정지 · F 전체 화면). Three.js 는 CDN(jsdelivr)에서, 글꼴은 Google Fonts 에서 받으므로 인터넷이 필요하다.
Claude 앱에서는 `.claude/launch.json` 의 `jaehun-paint` 로 바로 띄울 수 있다. 데이터(`data/`)는 jaehun-show 와 같은 파일을 복사해 두었다.

| 키 | 동작 |
|---|---|
| → / ← (또는 화면의 ◀ ▶, 위쪽 점) | 다음 장면 / 처음으로(또는 이전 장면) |
| 1 ~ 6 | 장면 바로가기 |
| Esc | 토큰 카드 닫기 |
| H | 자막·버튼 숨기기 (화면 녹화용) |
| A | 자동 넘김 켜기·끄기. 장면이 끝나면 다음 장면으로 (영상 녹화용) |
| Space | 정지 · 재생 |
| F | 전체 화면 |
| 마우스 드래그 | 카메라 돌려보기 (몇 초 뒤 연출 카메라로 돌아옴) |
| 아래 막대 클릭 | 장면 안에서 탐색 |

주소로 바로 가기: `#3@7.5` = 3번 장면 7.5초.

## 데이터 (data/, Git 제외)

AI Hub 원본 좌표가 들어 있어 커밋하지 않는다. 다시 만들려면:

```bash
# numpy 만 있으면 원본·귀 오류·토큰·격자까지
python tools/extract.py --repo <저장소 루트> --aihub C:/aihub
# torch 가 있으면 E5·E4b 디코더 복원까지 (--mlsrc 는 ml/vq/model.py 가 있는 루트)
python tools/extract.py --repo <저장소 루트> --aihub C:/aihub --decode --mlsrc <ml 소스 루트>
```

디코더로 다시 만든 토큰이 `tokens_e5.json` 과 정확히 일치하는지 추출 때 확인한다 (일치했다).

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | HUD(테이프 쪽지 자막·물감 숫자 카드·노란 물감 버튼·검색·토큰 카드·붓질 전환), 시안과 같은 SVG 필터(rough·wash), 색·글꼴 토큰 |
| `src/main.js` | 붓질 전환, 장면 색칠(G.scene), 선 떨림, 종이 얼룩 배경·여백 낙서, 시간, 키보드, 클릭·호버, 카드, 검색, 숫자 세기 |
| `src/util.js` | 수채 재질 `paint()`, 먹선 `inkMaterial()`·`inkify()`, 캔버스 수채 얼룩(`washBlob`·`washRect`), 글자 스프라이트, 글리프 |
| `src/stage.js` | 투명 렌더러, 따뜻한 빛, 갈색 그림자, 바닥 물감 웅덩이 |
| `src/skeleton.js` | 수채 캐릭터(먹선), `setPaint`, 연필 밑그림 `Tracing`, 굵은 선 `FatLines` |
| `src/typecase.js` | 512칸 스티커판(인스턴스 2개 + 먹선), 칸마다 색칠(aPaint), 붓 지나가며 칠하기 `paintSweep` |
| `src/fx.js` | 물감 방울, 물감 번짐 `bloom` |
| `src/bars.js` | 연필 윤곽 뒤에 붓이 아래에서 위로 칠하는 막대그래프 |
| `src/scenes/*.js` | 장면 여섯 개. `update(t)` 는 t 로만 계산해서 앞뒤로 긁어도 같은 그림 |
| `tools/extract.py` | 데이터 추출(+디코더), `tools/serve.py` 캐시 없는 개발 서버 |

## 공유 주의

장면 1~6 전부 AI Hub 원본 동작이 화면에 나온다. 팀 발표·수업 제출용이고, 공개 웹에 올리려면 원본 사람(먹색) 대신 디코더 출력만 남겨야 한다.
