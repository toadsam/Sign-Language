# 손짓의 알파벳 · 자모표 — 3D 발표 (재훈 파트)

브라우저에서 전체 화면으로 띄우는 발표용 3D 무대. 실제 AI Hub 동작 좌표와 E5·E4b 자모표 디코더가 복원한 좌표를 그대로 쓴다.
귀여운 컨셉: 팀 앱의 보라·라벤더 + 1학기 '꾸민 모습' 캐릭터(갈색 머리, 하늘색 옷, 오른손 복숭아·왼손 민트 소매끝).
캐릭터는 실제 125점 중 상체 13 + 양손 42를 그대로 따라 움직이고, 머리는 두 눈·목으로 방향만 잡는다(표정은 데이터에서 만들지 않음).
512칸 '동작 글자 스티커판'이 시그니처. 장면 전환은 노랑·분홍·보라 비눗방울 와이프, 글자는 한 자씩 튀어나오고 큰 숫자는 세어 올라간다.

만져 볼 수 있는 것: 스티커 칸을 누르면 그 토큰 카드(0.13초 동작, 단어·문장 클립 수, 자주 나오는 단어), 캐릭터를 누르면 콩 뛰기,
'단어로 찾기'(장면 1·2·6)에 "학교"를 치면 그 단어에 자주 나오는 토큰이 반짝, 장면 3의 "귀 제자리로 돌려놓기" 버튼.

## 실행

```bash
python docs/presentation/jaehun-show/tools/serve.py 8766
```

`http://127.0.0.1:8766` 을 연다. 512칸만 따로 보려면 `http://127.0.0.1:8766/grid.html` (모든 칸이 계속 움직이고, 칸을 누르면 크게 보기 · ←/→ 로 이웃 토큰 · 단어로 찾기 · Space 정지 · F 전체 화면). Three.js 는 CDN(jsdelivr)에서, 글꼴은 Google Fonts 에서 받으므로 인터넷이 필요하다.
Claude 앱에서는 `.claude/launch.json` 의 `jaehun-show` 로 바로 띄울 수 있다.

| 키 | 동작 |
|---|---|
| → / ← (또는 화면의 ◀ ▶, 위쪽 점) | 다음 장면 / 처음으로(또는 이전 장면) |
| 1 ~ 6 | 장면 바로가기 |
| Esc | 토큰 카드 닫기 |
| H | 자막·버튼 숨기기 (화면 녹화용) |
| A | 자동 넘김 켜기·끄기. 장면이 끝나면 다음 장면으로 (영상 녹화용) |
| Space | 정지 · 재생 |
| F | 전체 화면 |
| 마우스 드래그 | 카메라 돌려보기 (몇 초 뒤 연출 카메라로 돌아옴) |
| 아래 막대 클릭 | 장면 안에서 탐색 |

주소로 바로 가기: `#3@7.5` = 3번 장면 7.5초.

## 데이터 (data/, Git 제외)

AI Hub 원본 좌표가 들어 있어 커밋하지 않는다. 다시 만들려면:

```bash
# numpy 만 있으면 원본·귀 오류·토큰·격자까지
python tools/extract.py --repo <저장소 루트> --aihub C:/aihub
# torch 가 있으면 E5·E4b 디코더 복원까지 (--mlsrc 는 ml/vq/model.py 가 있는 루트)
python tools/extract.py --repo <저장소 루트> --aihub C:/aihub --decode --mlsrc <ml 소스 루트>
```

디코더로 다시 만든 토큰이 `tokens_e5.json` 과 정확히 일치하는지 추출 때 확인한다 (일치했다).

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | HUD(말풍선 자막·큰 숫자 카드·버튼·검색·토큰 카드·비눗방울 전환), 색·글꼴 토큰 |
| `src/main.js` | 장면 전환 와이프, 시간, 키보드, 클릭·호버, 카드, 검색, 숫자 세기 |
| `src/stage.js` | 투명 렌더러, 빛, 그림자, 둥근 무대판 |
| `src/skeleton.js` | 귀여운 캐릭터(콩 몸통·소매·통통 손가락·동그란 머리), 콩 뛰기 |
| `src/typecase.js` | 512칸 스티커판(인스턴스 2개), 글리프 시트, 날아다니는 스티커, 단어 검색 |
| `src/fx.js` | 별 반짝이 |
| `src/bars.js` | 통통 솟는 둥근 막대그래프 |
| `src/scenes/*.js` | 장면 여섯 개. `update(t)` 는 t 로만 계산해서 앞뒤로 긁어도 같은 그림 |
| `tools/extract.py` | 데이터 추출(+디코더), `tools/serve.py` 캐시 없는 개발 서버 |

## 공유 주의

장면 1~6 전부 AI Hub 원본 동작이 화면에 나온다. 팀 발표·수업 제출용이고, 공개 웹에 올리려면 원본 사람(먹색) 대신 디코더 출력만 남겨야 한다.
