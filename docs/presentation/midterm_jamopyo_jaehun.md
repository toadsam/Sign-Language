## 3. 어떻게 쟀나

- **처음 보는 사람**의 동작을 토큰으로 바꿨다 되돌렸을 때 관절이 평균 몇 mm 어긋나는지 (손 · 손가락 · 상체)
- **자모표 사용률**: 512개 중 실제로 쓰이는 비율. 관문 기준 50% 이상 (몇 개만 쓰면 표현력이 없다)
- 학습: GCP 서울 T4 GPU, 실험 한 번 약 1 ~ 2시간 · 수백 원 (AI Hub 약관상 해외 서버는 쓰지 않음)

## 예상 질문과 답

- **"mm 숫자가 생성 품질인가요?"** 아니요. 실제 동작을 토큰으로 바꿨다 되돌린 오차, 즉 토큰 방식이 낼 수 있는 **상한**입니다. 생성 결과는 받아쓰기 모델이 나온 뒤 같은 잣대로 잽니다.
- **"B1 52.7mm면 B1이 틀렸다는 건가요?"** 아니요. 다른 사람이 같은 단어를 하면 그만큼 다르다는 기준값입니다. 우리 생성 결과가 이 값보다 가까우면 "사람 사이 차이 수준"이라고 말할 수 있습니다.
- **"얼굴 표정(비수지)은요?"** 이번 자모표는 손과 상체만 만들고 얼굴은 평균 얼굴입니다. 얼굴을 함께 넣으면 손이 3.6mm 나빠졌습니다. 문장 데이터의 비수지는 의문형(약 3%)뿐이라, 필요하면 얼굴 전용 자모표를 따로 둡니다.
- **"왜 512개?"** 1024개로 늘리면 오히려 손이 1.8mm 나빠졌고, 받아쓰기가 고를 선택지도 두 배가 됩니다.
- **"데이터에 없는 단어도 만들 수 있나요?"** 없습니다. 학습한 단어(단어 3,000개, 문장 형태소 449개)의 새 조합만 만듭니다.
- **"AI가 다 한 것 아닌가요?"** 데이터 문제(귀 좌표)를 어떻게 고칠지, 얼굴을 뺄지, 문장을 넣을지, v1을 무엇으로 할지는 결과를 보고 직접 정했습니다. 판단 과정은 `docs/ai-log/jaehun.md`에 날짜별로 남겼습니다.
