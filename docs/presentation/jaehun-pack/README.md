## 4. 결정과 근거 (질문 받으면 이렇게)

| 결정 | 왜 |
|---|---|
| 2D 137점 대신 **3D 125점** | AI Hub에 3D가 있고 5방향이 다 같아 정면만 읽으면 됨. 아바타에 바로 연결 가능. 하체 12점은 10px 간격 가짜 값이라 뺌 |
| 손실에 **손가락 상대좌표 + 손 가중치 2배** | 평균 오차만 보면 손가락이 뭉개져도 작게 나옴 |
| 귀·눈을 **버리지 않고 대칭으로 다시 계산** | 처음엔 튄 프레임만 보간하려 했는데, 왼쪽 귀가 1만 6천 클립에서 코에서 평균 3.3m 떨어진 채 **계속** 있었음. 보간은 틀린 위치로 "고쳐질" 뿐. 1,144클립 회복 |
| 10fps 클립 985개 제외 | 영상 길이와 프레임 수가 3배 차이, 손목 이동이 정상의 2.5배. 나중에 살릴 수 있게 dur_ratio를 meta에 남김 |
| 평가는 **학습에 없는 두 사람**으로 | 사람 일반화가 목표. 모든 모델(자모표·받아쓰기·읽는 모델)이 같은 REAL03·12로 평가해야 비교표가 맞음 |
| **얼굴은 자모표에서 뺌** (E2) | 얼굴을 넣으면 손이 3.6mm 나빠짐. 얼굴은 사람마다 다른 얼굴 모양을 외우는 쪽에 가까움. 비수지는 의문형 3%뿐 |
| **512개 유지** (E4a) | 1024개로 늘리면 손이 1.8mm 더 나쁘고 받아쓰기 선택지가 두 배 |
| **v1은 E5 (단어+문장)** | 단어로만 배우면 문장 속 단어 50.6mm, 전환 52.7mm. 문장은 빠르고 앞뒤와 이어짐(동시 조음) |
| 새 조합 문장을 **단어 열 단위**로 뗌 | 2,000문장의 단어 열이 1,101종뿐. 문장 번호로 떼면 같은 단어 열이 다른 번호로 학습에 남음 |
| GCP **서울** 리전, AI Hub 문의 없이 | 약관이 막는 건 국외 반출. 올리는 건 변환 좌표(npy)뿐, 학습에만 쓰고 비공개 |
| 생성 담당과 채점 담당 분리 | 만드는 사람이 채점까지 하면 지표를 자기 쪽에 맞추게 됨 |

### 예상 질문

- **mm 숫자가 생성 품질인가요?** 아니요. 실제 동작을 토큰으로 바꿨다 되돌린 오차, 토큰 방식의 **상한**입니다. 생성 결과는 받아쓰기 모델이 나온 뒤 같은 잣대로 잽니다.
- **B1 52.7mm면 B1이 틀렸다는 건가요?** 아니요. 다른 사람이 같은 단어를 하면 그만큼 다르다는 기준값입니다. 생성 결과가 이보다 가까우면 "사람 사이 차이 수준"입니다.
- **얼굴 표정은요?** 이번 자모표는 손과 상체만, 얼굴은 평균 얼굴입니다. 얼굴을 넣으면 손이 3.6mm 나빠졌습니다. 필요하면 얼굴 전용 자모표를 따로 둡니다.
- **왜 512개?** 1024개로 늘리면 손이 1.8mm 나빠졌고 받아쓰기 선택지도 두 배입니다.
- **없는 단어도 만들 수 있나요?** 없습니다. 학습한 단어(3,000개, 형태소 449종)의 새 조합만 만듭니다.
- **AI가 다 한 것 아닌가요?** 귀 좌표를 어떻게 고칠지, 얼굴을 뺄지, 문장을 넣을지, v1을 뭘로 할지는 결과를 보고 직접 정했습니다. 판단 과정은 `docs/ai-log/jaehun.md`에 날짜별로 있습니다.
- **코드 사용률 50% 관문은?** 이미 97~100%라 관문으로 의미가 없어졌습니다. 실제 관문은 손 오차 개선과 미학습 사람 손모양입니다.
- **설계서 목표 손가락 12mm는?** 지금 20.6mm입니다. 잠정 목표였고, 정식 데이터 실측이 나온 뒤라 근거를 다시 봐야 합니다.
