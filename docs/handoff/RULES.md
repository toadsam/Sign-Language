## 1. 서버 (GCP `sign-ml`)

### 1-1. 기본 사실
- 서울 리전, Spot n1-highmem-8 (8코어 · 52GB) + **T4 GPU 1개**, 디스크 `/data` 147GB
- **요금은 켜 둔 시간만큼 재훈 계정으로 나간다.** 시간당 약 400원. 하루 켜 두면 약 1만 원
- 꺼져 있어도 디스크 보관비 월 약 1.8만 원은 나간다
- Spot 서버라 **구글이 예고 없이 끌 수 있다** (지금까지 2일에 1번꼴). 학습은 2,000회마다 저장되니 같은 명령에 `--resume`을 붙이면 이어진다

### 1-2. 켜기 · 들어가기 · 끄기
1. 콘솔 https://console.cloud.google.com/compute/instances?project=signHandBack → `sign-ml` **시작** (1분)
2. **SSH** 버튼 → 브라우저 터미널. 자기 구글 계정 이름으로 들어간다 (홈은 `/home/<이름>`, 비어 있는 게 정상)
3. 공용 파일은 전부 `/data` 아래. 먼저 `cat /data/handoff/README.md`
4. 다 쓰면 콘솔에서 **중지** (아래 1-4 확인 후)

### 1-3. 동시에 쓸 때 — 가장 중요
접속은 여러 명이 동시에 해도 된다. 문제는 **GPU와 메모리가 하나**라는 것.

| 하는 일 | 동시에 해도 되나 |
|---|---|
| 파일 보기, 코드 읽기 · 고치기, `--subset` 짧은 확인(1 ~ 2분) | ○ 언제든 |
| 긴 학습 (10분 이상, GPU 사용) | **한 번에 한 사람만** |

- 긴 학습을 돌리기 전에 **단톡에 "서버 학습 돌린다, 약 N시간"** 한 줄
- 다른 사람이 돌리는 중이면 기다리거나, `--subset 300 --iters 400` 같은 짧은 확인만 한다
- 지금 누가 돌리는지 확인: `nvidia-smi` (GPU 쓰는 프로세스가 보인다), `ps -u <이름>` 또는 `who`
- 긴 학습은 **자동 종료**를 붙인다 (1-5). 끝나면 서버가 스스로 꺼져서 다음 사람이 켜고 쓰면 된다

### 1-4. 끄기 전에
**「중지」는 서버에 들어와 있는 모든 사람의 작업을 끊는다.**
- 끄기 전에 `nvidia-smi`로 학습이 도는지 본다. 돌고 있으면 그 사람 것이다 → 끄지 말고 단톡에 묻는다
- 자동 종료를 건 학습은 알아서 꺼지니 손대지 않는다
- 자기만 쓰고 있었으면 바로 꺼도 된다

### 1-5. 학습 명령 틀
```bash
source /data/venv/activate
cd /data/code/ml
mkdir -p /data/work/<이름>

# 짧은 확인 (1 ~ 2분, 동시 사용 OK)
python -m vq.train --data /data/full --run /data/work/<이름>/test --split signer --subset 300 --iters 400 --no-record

# 긴 학습: 끝나면(실패해도) 2분 뒤 서버 종료. 로그는 파일로
nohup bash -c '<학습 명령>; sudo shutdown -h +2' > /data/work/<이름>/log.txt 2>&1 &
tail -f /data/work/<이름>/log.txt        # 보다가 Ctrl+C 로 나가도 학습은 계속된다

# 구글이 중간에 껐으면: 서버를 다시 켜고 같은 명령에 --resume
```

### 1-6. 폴더 — 건드려도 되는 곳 / 안 되는 곳

| 폴더 | 누구 것 | 규칙 |
|---|---|---|
| `/data/full`, `/data/full_sen`, `/data/full_all` | 재훈 (계약 ①) | **읽기만.** 고치거나 지우지 않는다. 품질 문제를 찾으면 단톡에 |
| `/data/runs/vq_*`, `/data/runs/tokens_*.json` | 재훈 (계약 ②) | 읽기만 |
| `/data/handoff/` | 재훈 | 읽기만. 설명이 틀렸으면 단톡에 |
| `/data/code/` | 저장소 사본 | 읽기만. **여기서 코드를 고치지 않는다** — 저장소에서 고치고 커밋한다. 재훈이 가끔 최신으로 덮어쓴다 |
| `/data/work/<이름>/` | 각자 | 자유. 자기 폴더만. 다 쓴 큰 파일은 지운다 |
| `/home/<이름>/` | 각자 | 자유. 데이터를 여기 복사하지 않는다 (디스크 30GB로 작다) |

- 자기 코드를 서버에서 돌리려면 `git clone`을 `/data/work/<이름>/`에 하거나, 로컬에서 고친 파일을 올린다
- 디스크가 100GB를 넘기 시작하면 단톡에. `df -h /data`

### 1-7. 설치
- 공용 환경 `/data/venv/activate` = torch(cu126) · numpy · scipy · matplotlib. **여기에 패키지를 추가하지 않는다** (다른 사람 환경이 깨진다)
- 다른 패키지가 필요하면 자기 venv: `python3 -m venv /data/work/<이름>/venv && source /data/work/<이름>/venv/bin/activate && pip install torch --index-url https://download.pytorch.org/whl/cu126 ...`
- `sudo apt install`은 재훈에게 먼저 말한다

### 1-8. 문제가 생기면
- 서버가 안 켜진다 → Spot 자원 부족일 수 있다. 10분 뒤 다시. 계속 안 되면 재훈에게
- SSH 버튼이 안 된다 → 권한 문제. 재훈에게
- `cuda False` 나온다 → `nvidia-smi` 해 보고 안 되면 재훈에게 (드라이버 문제)
- 실수로 뭔가 지웠다 → 바로 단톡에. 데이터는 재훈 노트북에 사본이 있다

## 2. 데이터 (AI Hub 약관)

- **AI Hub 「수어 영상」 이용 신청이 승인된 사람만** 데이터를 본다. 승인 안 된 사람에게 서버 접속 권한도 주지 않는다
- 데이터(원본, 변환 npy, meta, 토큰 파일, sentences.jsonl, 원본 좌표가 든 뷰어 HTML)는 **서버와 승인된 사람의 컴퓨터 밖으로 내보내지 않는다.** 구글 드라이브 공개 링크, 카톡 단톡 파일, 공개 저장소 모두 안 된다
- 저장소에는 `data/`, `runs/`, `*.npy`, `*.pt`, `tokens*.json`을 커밋하지 않는다 (`ml/.gitignore`). 코드 · 분할표 · 숫자 · 요약 그림은 된다
- 발표 자료에 넣어도 되는 것: 숫자, 그래프, 막대인간 그림, 자모표 격자(디코더가 만든 좌표). 넣으면 안 되는 것: 원본 영상, 수행자 얼굴
- 결과물에 출처 표기: **"한국지능정보사회진흥원 AI Hub 「수어 영상」 데이터 활용"**
- AI 도구(Claude · ChatGPT 등)에 데이터 내용을 통째로 붙여 넣지 않는다. 코드와 요약 숫자로 충분하다
- 승인은 2027년 1월경 만료. 그 뒤 쓰려면 재신청

## 3. 코드 · 저장소

`CLAUDE.md`(팀 공통 규칙)와 같다. 요약:

- 브랜치 `feature/<모델>-<이름>`, 커밋 `[ADD]`/`[FIX]`/`[REFACTOR]` + 한국어 요약 + ` -이름`
- **자기 폴더만 고친다.** 재훈 `ml/prep` `ml/vq` `ml/common` · 지헌 `ml/gen` `ml/serve` `backend` · 승현 `ml/recog` `ml/eval` · 승혁 `ml/cam` `viewer` `frontend*`. 남의 폴더를 고쳐야 하면 PR 설명이나 단톡으로 요청
- `ml/common/`은 재훈 리뷰 후 병합
- **계약 5개(`docs/contracts.md`)의 형식 · 함수 모양은 네 명 승인 없이 바꾸지 않는다**
- main에는 PR로 합친다. 강제 push · 브랜치 삭제 · `git reset --hard`는 하지 않는다
- AI를 쓴 작업은 `docs/ai-log/<이름>.md`에 한 항목씩 (목표 / AI에게 맡긴 것 / 바꾼 것 / 내가 판단한 것 / 검증 / 남은 것). 커밋 끝에 `Co-Authored-By` 줄

## 4. 평가 — 모든 모델 공통

숫자를 비교표에 나란히 놓으려면 전원이 같은 조건이어야 한다.

| 규칙 | 내용 |
|---|---|
| 분할표 | `ml/splits/full.json` · `full_sen.json` · `full_all.json`. **평가는 반드시 REAL03 · REAL12**(처음 보는 사람), 검증은 REAL04 · REAL11, 나머지 12명이 학습 |
| 제외 클립 | 분할표 `exclude.clips`. `apply_split`을 쓰면 자동으로 빠진다. 직접 거를 때도 빼야 한다 |
| 라벨 조건 | 라벨이 필요한 모델(받아쓰기 · 읽는 모델)은 `label == "ok"`이고 `0.85 ≤ dur_ratio < 1.5`인 클립만 |
| 평가 문장 | 문장 모델은 `full_sen.json`의 `heldout_sentences`에 걸리는 클립(gloss가 `sequences`에 있거나 item이 `items` · `question_items`에 있음)을 **학습에서 뺀다.** 평가는 그 클립 중 REAL03 · REAL12 것 150개 |
| 토큰 버전 | `tokens.json`의 `vq_version`과 디코더 `model.pt`는 **같은 버전끼리만.** 학습한 체크포인트에 버전을 기록 |
| 자모표 동결 | 11/7 v1 확정 뒤에는 바꾸지 않는다 (v2는 11/21까지 꼭 필요할 때만) |
| 채점관 | 읽는 모델은 실제 사람 동작으로만 학습. 생성 결과로 학습하지 않는다 |
| 기준선 | B1 · B2 · 우리 방법을 같은 데이터, 같은 평가 사람, 같은 지표 함수(`common/metrics.py`)로 잰다. B2는 우리 방법과 같은 크기 · 같은 학습 시간 |
| 숫자 기록 | 자모표 실험은 `ml/experiments.md`에 자동으로 한 줄씩. 다른 모델도 run 폴더에 `summary.json`을 남긴다 |

## 5. 매번 확인하는 목록

**서버 켜기 전**
- [ ] 단톡에 지금 쓰는 사람이 있나 봤다
- [ ] 긴 학습이면 "돌린다, N시간" 알렸다

**학습 돌릴 때**
- [ ] `/data/work/<이름>/` 안에 결과를 둔다
- [ ] 분할표 · 제외 · 라벨 조건 · (문장이면) heldout 적용했다
- [ ] 긴 학습은 `nohup ... ; sudo shutdown -h +2` 로 걸었다

**끄기 전**
- [ ] `nvidia-smi` 로 남의 학습이 안 도는지 봤다
- [ ] 큰 임시 파일 지웠다

**결과를 공유할 때**
- [ ] 숫자 · 그림만 올린다. 데이터 · 모델 파일은 저장소에 안 올린다
- [ ] AI 개발 기록에 한 항목 붙였다
