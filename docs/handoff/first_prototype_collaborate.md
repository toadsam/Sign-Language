### 1.1 번역기는 얼마나 정확한가

**번역기가 하는 일**: 한국어 문장을 수어 단어 순서(글로스 열)로 바꾼다.
예) "저는 학교에 갑니다." → `나 · 학교 · 가다`

**정답이 하나가 아니다**
- 학습 자료(엑셀)에는 문장 번호가 2,000개 있지만, 한국어 문장은 590종류뿐이다.
- 그래서 같은 한국어 문장이 여러 번호에 들어 있고, 번호마다 정답 글로스 열이 다른 경우가 있다.
- 왜 다른지는 데이터에 기록이 없다. 작업자 차이, 같은 뜻의 다른 수어 표현, 표기 차이 등이 섞여 있을 것이다.
- 어쨌든 **같은 문장을 옮기는 정답이 여러 개일 수 있다.**

**어떻게 채점했나 (자동 점수)**
- 학습에 쓰지 않은 문장 76개를 번역기에 넣고 정답과 비교했다.
- 정답이 여러 개면 **그중 번역기 출력과 가장 비슷한 것**과 비교했다.
- 점수(F1)는 두 가지를 합친 값이다. 1에 가까울수록 좋다.
  - 번역기가 낸 단어 중 정답에도 있는 비율 → 엉뚱한 단어를 안 넣는지
  - 정답 단어 중 번역기가 빠뜨리지 않은 비율 → 단어를 안 빠뜨리는지

| | 점수 | 쉽게 말하면 |
|---|---|---|
| 번역기 | **0.79** | 정답 단어 10개 중 약 8개를 맞게 냄 |
| 정답끼리 | 0.85 | 같은 한국어 문장에 붙은 서로 다른 정답 글로스 열끼리 비교해도 이 정도만 일치함 |

→ 정답끼리도 0.85만 일치하므로, **0.85가 사실상 만점**이다. 번역기는 그 바로 아래에 있다.

**사람이 직접 본 판정**
- 자동 점수는 "정답과 단어가 같은가"만 본다. 뜻이 같은 다른 표현을 내면 틀린 것으로 셈한다.
- 그래서 학습에 쓰지 않은 문장 중 **무작위로 50문장**을 뽑아, 지헌이 번역기 출력과 정답을 나란히 보고 직접 판정했다.
- 판정 기준: 정답과 표현이 달라도 **뜻이 같고, 그 글로스로 동작을 그릴 수 있으면** 맞음.

| 판정 | 문장 수 | 비율 | 예 (지어낸 예) |
|---|---|---|---|
| 정답과 같음 | 15 | 30% | 정답 `나 · 학교 · 가다` / 번역기 `나 · 학교 · 가다` |
| 정답과 다르지만 뜻이 맞음 | 16 | 32% | 정답 `화장실 · 어디` / 번역기 `화장실 · 곳 · 무엇` |
| 단어가 빠짐 | 14 | 28% | "병원에 가고 싶어요" → `병원 · 저기 · 가다` ("싶다" 빠짐) |
| 엉뚱한 단어가 들어감 | 4 | 8% | 문장에 없는 단어가 끼어 있음 |
| 빠짐과 엉뚱함이 둘 다 | 1 | 2% | – |

→ **10문장 중 약 9문장은 엉뚱한 단어 없이 옮겨진다.** 그중 약 6문장은 뜻이 완전히 맞고, 약 3문장은 단어가 하나쯤 빠지지만 문장의 큰 뜻은 남는다. 엉뚱한 단어가 들어가는 경우는 약 1문장이다.

판정은 v4 출력으로 했다. v5n은 대체어 표만 더한 것이라 결과는 거의 같다.

**대체어 표 (v5n)**
- 글로스 표에 없는 말을 그릴 수 있는 글로스로 바꿔 준다. 학습 문장에서 자동으로 뽑은 49개 중 지헌이 직접 확인해 맞는 41개만 쓴다.
- 예: 주민등록증 → 신분증, 커피숍 → 카페, 휴대폰 → 핸드폰

| 문장 | v4 | v5n |
|---|---|---|
| 커피숍에 가고 싶어요. | 가다 | 카페 · 가다 |
| 휴대폰을 잃어버렸어요. | – | 핸드폰 · 잃어버리다 |
| 주민등록증이 있으세요? | 있다 | 신분증 · 곳 |

**발표에 쓸 한 줄**: "번역기는 정답끼리의 일치도(0.85)에 가까운 0.79를 보였고, 사람이 직접 판정했을 때 90%가 엉뚱한 단어 없이 옮겨졌다(뜻이 완전히 맞음 62%, 단어 하나쯤 빠짐 28%)."

## 2. 왜 OpenAI 대신 madi 번역기를 쓰나

1학기 Spring 번역은 OpenAI(LLM)가 형태소 정리와 어순 변환을 한 번에 한다. 문장 모델에서는 이것을 쓰지 않는다.

| | OpenAI (1학기) | madi 번역기 (지금) |
|---|---|---|
| 하는 일 | LLM이 문장을 보고 글로스 열을 지어냄 | madi는 형태소 분석만. 글로스 변환은 실제 수어 글로스 쌍으로 학습한 대응표가 함 |
| 같은 입력의 결과 | 매번 달라질 수 있음 (환각 포함) | 항상 같음 |
| 낼 수 있는 글로스 | 아무 말이나 | 글로스 표에 있는, 그릴 수 있는 것만 |
| 외부 API | 필요 (키, 비용, AI Hub 약관 문제) | 없음. 서버 안에서 돎 |
| VM에서 | 키가 없어 안 됨 | 됨 |

그래서 문장 모드에서는 **Spring이 번역을 하지 않고 추론 서버의 madi 번역기(`/translate`)를 부른다.**
설정 하나(`SIGN_GENERATION_TRANSLATOR=serve`)로 바뀌고, 기본값(`spring`)은 예전 동작 그대로다.

## 3. 승혁 질문에 대한 답 (프론트 · 화면 연결)

**요청은 그대로다.** `POST /api/sign/generate`에 `{"text": "일반 문장"}`.

**응답 형식도 그대로다 (계약 ⑤).** 바뀐 것은 일반 문장을 넣을 수 있게 된 것뿐이다. 예전에는 단어표의 단어만 넣어야 했다.
동작 길이 상한(1,800프레임, 60초)은 예전과 같다.

```
POST /api/sign/generate   {"text": "병원에 가고 싶어요."}
→ 200 {"fps": 30, "joints": 125, "frames": 152, "units": "shoulder", "data": "<base64 float32 [152×125×3]>",
       "tokens": [...38개], "segments": [{"gloss": "병원", "start": 0, "end": 70}, {"gloss": "가다", "start": 82, "end": 152}],
       "unknown": [], "source": "model"}
```

`segments`(11-14부터 켜짐): 문장 모드는 단어마다 `{"gloss", "start", "end"}`를 시간 순으로 보낸다. 30fps 프레임 번호, `end`는 끝 프레임 다음,
단어 사이 연결 구간은 빠진다(위 70~82). 화면에서는 재생 중인 프레임이 들어 있는 구간의 `gloss`를 자막으로 띄우면 된다. 위 숫자는 예시다.

**지원하지 않는 입력**

| 입력 | 응답 |
|---|---|
| 일부 단어를 못 그림 (예: "오늘 날씨가 좋아요." → 날씨) | 200. 그릴 수 있는 것만 만들고 `unknown: ["날씨"]` |
| 전부 못 그림 (예: "ㅋㅋㅋ") | 200. `frames: 0`, `data: ""`, `unknown: ["ㅋㅋㅋ"]`, `source: "baseline"` |
| 그릴 말이 하나도 안 남음 (예: "!!!") | 422 `{"error": {"code": "NO_GENERATABLE_INPUT", ...}}` |
| 빈 문자열, 형식 오류 | 400 `INVALID_REQUEST` |
| 서버 꺼짐 · 시간 초과 | 503 / 504 (예전과 같음) |

화면에서는 `unknown`이 비어 있지 않으면 "못 그린 단어: ..."를 보여 주면 된다.

**VM에서 켜기**: 예전 `serve_vm/start.sh`는 **단어 모델**을 켠다. 문장 모델은 새 스크립트로 켠다.

```
bash /data/work/jiheon/serve_vm_sentence/start_sentence.sh       # 끄기: 같은 폴더의 stop.sh, 상태: status.sh
```

- 접속(포트 연결), 8080 주소, 첫 요청이 느린 점은 예전 안내와 같다.
- 단어 모델과 문장 모델은 같은 포트(8000/8080)를 쓴다. 둘 중 하나만 켤 수 있다.
- 검증 화면을 보려면 접속할 때 8000 포트도 연결하고 `http://localhost:8000/verify`를 연다.

**테스트 문장** (11-15 VM, 번역기 v5n으로 확인)

| 문장 | 글로스 열 | 결과 |
|---|---|---|
| 저는 학교에 갑니다. | 나 · 학교 · 가다 | 전부 그림, 164프레임 |
| 지하철을 타고 집에 가요. | 지하철 · 타다 · 집 · 가다 | "집"만 unknown (빠진 단어 표시 확인용) |
| 커피숍에 가고 싶어요. | 카페 · 가다 | 대체어(커피숍 → 카페) 확인용, 128프레임 |
| 감사합니다. | 감사합니다 | 한 단어, 124프레임 |
| 버스 정류장이 어디예요? | 버스 · 곳 · 무엇 | 전부 그림 (의문문) |
