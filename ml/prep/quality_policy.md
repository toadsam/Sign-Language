# WORD 품질 분류 v0.1 (임시)

2026-10-14. 저장된 전처리 좌표 전체 클립 기준이다. 수어 의미 정확성을 보증하지 않으며 자동 삭제·보정·학습 필터를 적용하지 않는다. 전처리 이전 오류 원인도 확정하지 않는다.

## 기준

| 상태 | 동작 기준 |
|---|---|
| 학습 보류 (`hold`) | 순간 몸 손목–손 시작점 간격 > 100cm 또는 어느 관절이든 인접 프레임 이동 > 100cm |
| 추가 확인 (`review`) | 보류 조건 없이 순간 손목 간격 > 20cm 또는 관절 프레임 이동 > 50cm 또는 기록된 원본 클립 평균 손목 간격 > 5cm |
| 사용 가능 (`usable`) | 위 점검 기준에 걸리지 않음 |

엄격한 `>` 비교이므로 100cm는 100cm 초과가 아니다. 보류가 추가 확인보다 우선한다. 이동은 속도가 아니라 프레임 사이 거리다. 몸·손·얼굴 125점 모두 검사하며 귀도 몸 관절에 포함된다. 얼굴만의 문제로 동작이 정상인 클립도 보수적으로 보류될 수 있어 부위별 측정값을 CSV에 보존한다. active 밖의 문제도 전체 클립 기준에 포함한다.

## 라벨 구분

`motion_status`는 라벨과 독립적인 VQ-VAE용 동작 상태다. `status`는 단어 라벨까지 고려한 상태이며, 라벨 없음·빈 구간·파싱 실패가 있으면 학습 보류한다. 라벨이 연결되고 비어 있지 않아도 개별 형태소·시각 유효성은 아직 검증 전이다. REAL25 라벨을 REAL02에 임의 연결하지 않는다.

## 재현

`ml/`에서 다음을 실행한다. 기존 meta와 scan의 해시·ID 대응을 검사하며 원본 데이터 폴더 내부에 보고서를 쓰지 못하도록 제한한다.

```powershell
python -m prep.quality_lists --data C:/aihub/full --audit C:/aihub/audit_word --out C:/aihub/audit_word/quality_v0_1
```

출력은 `usable.csv`, `review.csv`, `hold.csv`, `all_clips.csv`, `summary.json`이다. 데이터와 파생 클립 목록은 Git에 올리지 않는다. 기준 변경 시 버전·이유·개수 변화를 기록하고 이후 고정 분할 및 평가 정책과 맞춘다. 현재 학습 코드는 이 목록을 자동으로 읽지 않는다.
