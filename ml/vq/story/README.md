# 손짓의 알파벳: 인터랙티브 연구 이야기

재훈의 데이터 정리와 VQ-VAE 연구를 설명하는 로컬 웹앱입니다. 팀의 `viewer/`와 독립적이며 Python 학습 코드, 데이터, 체크포인트를 수정하거나 실행하지 않습니다.

## 실행

이 폴더에서 실행합니다. Python 3.11 이상과 Node.js 22를 사용했습니다.

```powershell
python build_catalog.py
npm.cmd install
npm.cmd run dev -- --port 5187
```

`http://127.0.0.1:5187`을 엽니다. 해당 포트가 사용 중이면 다른 포트를 지정합니다. `build_catalog.py`는 Python 표준 라이브러리만 사용하며 현재 소스를 읽어 `catalog.json`을 생성합니다. 실제 배열·라벨·모델 파일은 읽지 않습니다.

## 구성

- 7장·28개 연출 장면, 750초(12분 30초)의 자동 재생 자막. 재생·일시정지·탐색·속도·재개·장면 선택과 세부 장면 앞뒤 이동.
- 두 사람의 위치·크기 맞춤, 귀 오류 발생·정지·확대·백업·보정, 학습/평가 표본 분리, 80프레임→20특징 압축, 코드북 선택·복원, 실험 수치 비교를 각각 다른 Three.js 동작으로 표현합니다. 실제 수어나 모델 복원으로 해석하지 않습니다.
- 시스템에 한국어 음성이 있으면 내레이션을 기본으로 켜며 사용자가 끌 수 있습니다. 없으면 자막으로 시작하며 음성 버튼으로 시도할 수 있습니다. 녹음된 내레이션이나 배경 음악은 없습니다.
- 각 장의 상세 해설, 직접 조절하는 계산 예시, 즉시 해설하는 확인 문제.
- 재훈 담당 최상위 Python 파일 25개, 함수·메서드·중첩 함수 127개의 실제 원문. 파일 안내, 핵심 함수 계산 해설, AST 문법 해설, 호출 목록, 줄 이동, 검색, 복사.
- 25개 파일 모두에 문제 상황·재훈이 한 일·3단계 입력/처리/결과 예시·담당 함수·다음 연결 파일을 넣었습니다. 총 75개 예시 단계이며 자동 재생 또는 단계별 선택이 가능합니다. 개념용 가상 예시와 기록의 실제 수치를 구분합니다.
- `#code/vq/model.py@MotionVQVAE.encode` 형태의 직접 링크. 함수 선택, 줄 번호와 내용은 생성 시점 소스에 대응합니다.
- 원본 근거: `ml/experiments.md`, `docs/ai-log/jaehun.md`, `ml/prep/quality_policy.md` 및 실제 Python 코드.

## 파일

| 파일 | 역할 |
|---|---|
| `src/content.js` | 검토한 한국어 이야기, 파일별 설명, 주요 함수 설명, 용어 |
| `src/main.js` | 재생 시간, 화면 전환, 코드 탐색, 퀴즈·실험 |
| `src/screenplay.js` | 28개 쉬운 내레이션·작업 요약·함수 연결 및 파일별 3단계 예시 |
| `src/cinema.js` | 장면별 연출, 카메라, 합성 골격·백업·분할·압축·비교 |
| `src/cinema.css` | 중앙 영화 장면·하단 자막·파일별 예시 화면 |
| `src/style.css` | 데스크톱·모바일, 키보드 초점, 동작 감소 설정 |
| `build_catalog.py` | AST로 실제 소스·함수 범위·문법 블록·해시 추출 |
| `tests/verify.mjs` | 브라우저 기능, 캔버스 픽셀, 데스크톱·모바일 검증 |
| `tests/cinema.mjs` | 28개 장면 배치, 25개 파일·75단계 예시와 오류 검증 |

소스가 바뀌면 catalog를 다시 생성하세요. `content.js`의 수동 해설과 실험 수치는 자동 업데이트되지 않습니다. 표시된 커밋은 생성 시점 HEAD이며 파일별 SHA256이 읽은 실제 파일을 식별합니다. 다른 팀원 소유 코드와 story 자체는 코드 탐색 범위에 포함하지 않습니다.

## 해석 주의

- E5는 몸·손 55점만 학습하고 얼굴 70점은 평균으로 채웁니다.
- E5 학습 뒤 SEN 이상치 58개 추가 제외와 문장 홀드아웃 선정이 있었습니다. 최신 split과 당시 E5 학습 조건을 구분합니다.
- `apply_split`은 `heldout_sentences`를 자동 적용하지 않습니다.
- `train.evaluate`의 클립 평균과 `eval_clips`의 프레임 평균을 분리합니다. E5의 혼합 test 손 28.2mm와 SEN test 28.1mm는 다른 평가입니다.
- 이 사이트의 수치는 저장소 기록 인용이며 모델을 재학습하거나 재평가해 측정한 것이 아닙니다.

## 빌드와 확인

```powershell
npm.cmd run build
# 별도 터미널에서 위 dev 서버를 켠 뒤
npm.cmd test
node tests/cinema.mjs
```

브라우저 검증은 기본적으로 Windows Chrome을 사용합니다. `STORY_BROWSER`에 실행 파일 경로, `STORY_URL`에 서버 주소를 지정할 수 있습니다. 스크린샷은 Git 제외된 `test-results/`에 저장합니다.

정적 배포 결과는 `dist/`입니다. 현재는 로컬 사용용으로 만들었으며 외부 업로드·배포하지 않습니다. 코드북과 데이터 파일을 번들에 포함하지 않습니다. 글꼴은 설치된 시스템 한글 글꼴을 사용하며 외부 글꼴 서버에 요청하지 않습니다. Three.js와 아이콘은 npm 의존성에서 로컬로 제공합니다.
